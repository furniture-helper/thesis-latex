\section{Page Classifier}\label{sec:page_classifier_evaluation}

The main metric which can be used to evaluate the performance of the page classifier is the F1 score, which is a measure of the accuracy of the classifier.
The page classification model, which was trained and evaluated on a dataset of \texttt{2,430} product pages and \texttt{1,014} non-product pages, achieved an F1 score of \texttt{0.971} on the validation dataset, which is a good indication of the model's performance.
These figures may deviate slightly from those in Section~\ref{subsec:page_classifier_model_evaluation} because the model was retrained on a larger dataset, which was not available during the initial model comparison phase.

Another important metric to consider is the time taken to classify a batch of pages, which is a measure of the speed of the classifier.
The page classification inference task is executed in three phases, as described in Section~\ref{subsec:page_classifier_inference_phase}.
Table~\ref{tab:page-classifier-runtime} summarizes the execution time of each phase across three runs.
Across all runs, \texttt{72,424} pages were classified in a total of \texttt{8,885.66} seconds (\textasciitilde{}148 minutes).
This represents an average time of \texttt{40.89} minutes to classify \texttt{20,000} pages, which is a good indication of the speed of the classifier.

An interesting observation from the results in Table~\ref{tab:page-classifier-runtime} is that the time taken to generate the dataset for inference is comparable to the time taken for inference itself.
This is due to the fact that the dataset generation phase involves fetching the list of recently crawled pages from the database, and downloading the HTML content of each page of S3, which is a time-consuming process.
We can also see that the actual inference times are fairly consistent across runs.
This is because most of the time taken for inference is spent on downloading the dataset and model from S3, which is a network-bound operation and is not affected by the size of the dataset.
The actual inference time is usually around \texttt{600} seconds (\textasciitilde{}10 minutes) for a batch of \texttt{20,000} pages.
